# HMTI Student Information Center

Website informasi digital Himpunan Mahasiswa Teknik Informatika yang dibuat sebagai bagian dari penugasan pendaftaran HMTI.

## Deskripsi

HMTI Student Information Center merupakan website sederhana yang menyediakan informasi mengenai Himpunan Mahasiswa Teknik Informatika (HMTI), informasi organisasi, kegiatan serta kontak.

Website ini dikembangkan menggunakan HTML, CSS, dan JavaScript dengan menerapkan konsep dasar pengembangan website seperti struktur halaman, styling, responsive design, interaksi pengguna, dan validasi form.

## Fitur

- Halaman Utama (Home)
- Informasi seputar HMTI
- Informasi kegiatan
- Filter kegiatan berdasarkan kategori
- Form pendaftaran kegiatan
- Validasi form menggunakan JavaScript
- Dark mode dan light mode
- Scroll animation
- Halaman kontak dan media sosial
- Responsive design

## Teknologi

- HTML
- CSS
- JavaScript
- Font Awesome
- Google Fonts
